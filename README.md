# World News 25
Questa applicazione sarà un client per poter visualizzare dati recuperati da [News API](https://newsapi.org)

## Esercitazione 3 (24 ottobre)

In questa esercitazione abbiamo creato il progetto World News da zero. In particolare, è stato importato un foglio di stile da [questo sito](https://material-foundation.github.io/material-theme-builder/) e successivamente è stata creata la pagina `LoginActivity`

È stata modificata l'Activity di partenza da `MainActivity` a `LoginActivity` modificando il file `manifests/AndroidManifest.xml`
